# Worked examples

Inputs generated by ANT.UI for the four worked examples of the user manual (section "Worked examples").
Examples 2–4 use the settings of the three panels of Fig. 2 of the ANT.UI paper.

| Folder | What it is | Junction | Settings |
|---|---|---|---|
| `1_single_junction` | One transport calculation | Au(111) tip / benzene / Au(111) tip, 52 atoms | HSE06, no optimisation |
| `2_pull_every_step` | Fig. 2(a): symmetric pull | same junction | 20 configurations, gap +0.1 Å per step (each electrode 0.05 Å), molecule relaxed at every step |
| `3_rotation_first_step` | Fig. 2(b): rotation | Au(111) tip / glycerol / Au(111) tip, 54 atoms | PBE, 0–90° in 15° steps, molecule relaxed at the first step |
| `4_grid_first_step` | Fig. 2(c): tip scan | Au(111) slab / toluene / Au(111) tip, 75 atoms | PBE, 10 × 10 points over 8 × 8 Å, molecule relaxed at the first step |

Every folder contains `ANTUI_summary.txt`, the full description of the model that ANT.UI showed before writing: atoms per region, basis sets and pseudopotentials per element and region, charge and multiplicity, optimisation constraints and sequence settings.

To regenerate the folders without the graphical interface, run this from the repository root:

```bash
python Examples/make_examples.py
```

The job header in `launchANT.sh` is the placeholder from the shipped `USER_CONF.txt`. Set your cluster's header there and regenerate the folders, or edit `launchANT.sh` directly, before submitting.
